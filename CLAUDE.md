# PODU — Claude Context

## Project

**PODU** is an interactive AI podcast web app. A recruiter clones the repo, runs `bun dev`, enters their ElevenLabs API key in-app, and has a real-time voice conversation with one of three AI podcast hosts (fun / educational / deep) on topics they choose.

**Current milestone:** Portfolio-demo refactor — stripping Clerk + Convex, replacing with `bun:sqlite` + `iron-session`. The app must run with only an ElevenLabs API key and SQLite's local file. Core value: clone → `bun dev` → conversation in under five minutes.

## Hard Constraints (milestone-critical)

These come from research/PITFALLS.md and are easy to get wrong:

1. **Never put `ELEVENLABS_API_KEY` in `.env` or `Bun.build` `define`.** The key is entered in-app, sealed via `iron-session`, and stored only in an httpOnly cookie. It must never reach the browser bundle.
2. **SQLite connection is a `globalThis` singleton** in `src/lib/db.ts`. `bun --hot` re-executes module scope on every file save; without `globalThis`, you leak connections.
3. **Use `sealData` / `unsealData` from `iron-session`**, not `getIronSession`. Bun's `Response` is immutable and incompatible with the higher-level API.
4. **Remove Clerk and Convex packages before deleting imports from source.** The TypeScript compiler surfaces every orphan when the types vanish — don't skip this forcing function.
5. **`buildFullPrompt()` must never return an empty override string.** ElevenLabs silently discards empty overrides; guard it with an assertion.
6. **`secure: process.env.NODE_ENV === "production"`** on the iron-session cookie — otherwise the cookie won't round-trip over plain-HTTP localhost and you'll see invisible 401 loops.

## Stack

- **Runtime:** Bun v1.1+
- **Frontend:** React 19, TypeScript strict, Tailwind 4, Shadcn/UI
- **Voice:** ElevenLabs Conversational AI (WebRTC) — `@elevenlabs/react`
- **DB:** `bun:sqlite` (built-in, single file)
- **Secrets:** `iron-session` cookie for the API key

## What to Avoid

- Introducing new external services or env vars (breaks the single-key setup story)
- Switching DB engines or adding ORMs (`bun:sqlite` raw SQL is sufficient)
- Rebuilding the existing host prompts in `src/api/agentPrompts.ts` — they are the portfolio differentiator
- Live transcription, post-call summary, usage tracking, billing — all explicitly out of scope for this milestone
